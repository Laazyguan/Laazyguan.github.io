# Xuezheng Guan — Personal Site

Bilingual (中文 / English) personal site for Robotics & AI recruiting.

## Live site
After GitHub Pages is enabled: `https://laazyguan.github.io/` (user site) or `https://laazyguan.github.io/<repo>/` (project site).

## Update open roles
Edit `jobs/index.json` and push. The homepage loads it automatically.

```json
{
  "updatedAt": "2026-10-09",
  "jobs": [
    {
      "titleZh": "机器人感知工程师",
      "titleEn": "Robotics Perception Engineer",
      "company": "Example Co",
      "location": "Bay Area / Remote",
      "descZh": "简短中文描述",
      "descEn": "Short English description",
      "tags": ["Robotics", "Perception"],
      "url": "https://example.com/job"
    }
  ]
}
```
